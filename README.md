# Небольшая анкета — V2.0

## Что изменено
- Новое лавандово-розовое оформление.
- Приветствие теперь «от меня», без имени Давида.
- Ровно 10 обновлённых вопросов.
- Команда `/myid` показывает числовой Telegram ID текущего пользователя.
- Ответы отправляются только на один фиксированный `OWNER_ID`.
- При неустановленном `OWNER_ID` сервер не притворяется, что ответы доставлены.
- Проверяется подпись Telegram Mini App `initData` и срок её действия.
- Нет публичной админ-панели и команд выдачи/передачи прав.

## Установка
1. Создай отдельного бота через `@BotFather`.
2. Временно запусти его с `BOT_TOKEN` и `WEBAPP_URL`, открой бота и отправь `/myid`.
3. Скопируй числовой ID из ответа и установи его как `OWNER_ID` в Railway Variables.
4. Добавь `BOT_TOKEN` и публичный HTTPS `WEBAPP_URL` этого Railway-сервиса.
5. Для постоянного хранения SQLite подключи Railway Volume к `/data` и установи `DB_PATH=/data/answers.db`.
6. Сделай redeploy. Проверь `/health`, затем открой бота и протестируй анкету.

## Защита
- `OWNER_ID` — числовой Telegram ID, не @username. Бот отправляет ответы только этому ID.
- Не добавляй токен в GitHub. `.env` исключён через `.gitignore`.
- Сделай GitHub-репозиторий Private и включи 2FA на GitHub, Railway и Telegram.
- Никому не передавай токен бота и доступ к Railway/GitHub.
- Владелец Telegram-аккаунта, который управляет ботом через BotFather, всё ещё может передать бота. Программный код не может отменить это право владельца.
- Любой, кто получит ссылку/имя бота, сможет открыть анкету; это не даёт ему доступ к ответам или настройкам Railway.
